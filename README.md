# 🥷 The Shinobi Page

A simple landing page inspired by the world of **Shinobis**, built with **React** and **GSAP**.

This is currently a **small and simple landing page project**, mainly focused on experimenting with UI design, animations, and 3D elements rather than building a complete website or application.

The goal was to create a visually engaging page with a strong and consistent theme while experimenting with modern web technologies.

## ✨ Features

* **Shinobi-inspired UI** with a dark and immersive visual identity
* **React** for building the interface
* **GSAP** for smooth animations and transitions
* **3D integration** to add depth to the page
* **Responsive design**
* Multiple sections combined into a single landing page

## 🛠️ Technologies

* **React**
* **JavaScript**
* **GSAP**
* **CSS**
* **3D / WebGL**

## 🎯 Project Goal

The main goal of this project was to experiment with **creative UI design, animations, and 3D elements** while building a landing page around a clearly defined theme.

For now, the project is intentionally **simple and limited to a landing page**. It is primarily a visual/UI experiment rather than a fully functional website.

I wanted to focus on creating a cohesive visual identity and exploring how animations and 3D elements can enhance a relatively simple page.
